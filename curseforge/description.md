# Ad Astra Flight Expansion (Unofficial Add-on)

Any armour in [Ad Astra](https://www.curseforge.com/minecraft/mc-mods/ad-astra)'s jet suit tag flies like the jet suit: hold jump to hover, hold jump and sprint to fly and glide, and toggle it with Ad Astra's Toggle Suit Flight key. Instead of energy, flying wears the chestplate's durability, and it stops before the chestplate breaks. For Ad Astra 1.15.21 on Forge 1.20.1. Ad Astra itself is still required.

## For Modpack Makers

- Add a full armour set to the item tag `ad_astra:jet_suit_items` with a datapack or KubeJS.
- Flying costs 1 durability a second by default; change it, or make flight free, with `durabilityPerSecond` in the server config.
- Install it on both the client and the server.
